# InferNex Agent v0.5.0-alpha.16

alpha.16 是 E1 SLO 对照实验与 E2 版本关联基础的首个增量，保留 alpha.15 的离线安装、Pi TUI、权限模式、只读网络诊断、报告和记忆能力。

本版新增：

- 现有 Bridge 渐进实验可选择管理员批准的固定 SLO profile，实际对基线与候选执行有界的非流式请求。只有 SLO 通过才晋级；退化与证据不足分开记录。
- 实验状态和 Dashboard 展示端到端 p95、成功率、串行成功请求吞吐及证据引用。未启用 SLO 的旧实验明确显示仅运行就绪与诊断门禁。
- `config-version record/show/list/verify` 将真实本地 Git commit 内的配置、前后快照及可选实验文件绑定为受保护的不可变记录。记录可离线核验，未提交工作树内容不混入 commit 版本。

使用步骤、profile 样例和 CLI 见 [SLO 与配置版本指南](https://github.com/lsjfy-open-com/infernex-agent/blob/develop/component/InferNex-Agent/docs/guides/slo-and-config-versions-zh.md)。SLO 默认关闭；用户需明确批准实验。配置版本记录需要本地 Git，其他现有运行功能不新增 Git 依赖。

## 安装或升级

下载对应管理节点架构的归档及校验文件后：

```bash
sha256sum --check infernex-agent-0.5.0-alpha.16-linux-*.tar.gz.sha256
tar -xzf infernex-agent-0.5.0-alpha.16-linux-*.tar.gz
cd infernex-agent-0.5.0-alpha.16-linux-*
sudo ./install.sh
sudo infernex-agent chat
```

升级继续创建本机恢复点；保留 alpha.15 或当前已知可用安装包。SLO 需要管理员另行配置固定场景和可达端点，版本命令不会替用户修改集群。

## 验收与边界

自动化验证覆盖 HTTP 双端点请求、门禁三态、证据持久化和恢复、配置漂移、实际 Git commit/replace-ref 与本地记录完整性。它不代替真实 NPU/Mooncake 现场验收；重复前缀请求不等于已确认 prefix hit。

本版尚不提供 TTFT/TPOT、并发容量压测、语义质量评估、原生 Kubernetes 写事务、自动修复补丁构建、生产灰度切流或完整 GitOps 回退。`config-version verify` 只校验本地记录完整性；当前快照不覆盖模板、权重、流量和数据。E1/E2 仍需后续增量，不能将本版称为完整自主修复系统。
