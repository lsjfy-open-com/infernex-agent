# InferNex Agent v0.5.0-alpha.15

alpha.15 是供管理节点现场验证的双架构离线实验包，完整保留 alpha.14 功能，并加入三项交互与运维能力：

- 工具调用默认压缩为一行状态、操作、目标和耗时，`Ctrl+O` 展开完整参数与结果；
- 报告和记忆使用“关键词 + UTC 日期时间”的可读文件名，hash 继续作为内容引用和快速索引；
- `/mode_change` 分别控制 `normal/root` 执行身份与 `manual/full` 批准策略。full 模式会持续执行任务，自动运行已分类的只读诊断和有界证据采集；集群部署、删除、实验、HCCL/iperf 压测及未知命令仍需人工批准。连续三次没有成功的新工具证据会暂停，失败、超时或取消的结果不会被计为进展。

包内继续包含 SSH、`kubectl exec`、CANN plog、PFC/HCCN、RDMA 与 HCCL 诊断能力、Pi v0.84.1、`rg` 和 `fd`。安装不访问 npm，也不要求宿主机预装 Node、Bun、Go 或 Python。

## 安装或升级

按管理节点架构下载一个归档及同名 `.sha256`：

```bash
sha256sum --check infernex-agent-0.5.0-alpha.15-linux-*.tar.gz.sha256
tar -xzf infernex-agent-0.5.0-alpha.15-linux-*.tar.gz
cd infernex-agent-0.5.0-alpha.15-linux-*
sudo ./install.sh
sudo infernex-agent chat
```

升级会创建恢复点；保留 alpha.14 或当前已知可用包。已有会话、证据、报告和记忆文件不会因升级而改名。进入 TUI 后执行 `/mode_change status` 检查默认状态；新建或恢复会话均从 `normal + manual` 开始。需要持续只读排障时执行 `/mode_change full`，需要读取 root 可见的本机路径时以 sudo 启动并执行 `/mode_change root full`。

Mooncake prefix hit 超时的现场取证步骤见[Mooncake prefix hit 超时网络验证](../guides/mooncake-prefix-hit-network-validation-zh.md)。该流程用于验证交换机拥塞是否与超时同窗出现，不预设交换机为根因。
