# 请求方提供真实脱敏证据清单

本清单用于将合成 starter kit 扩展为真实现场验收。请求方保留原件，只交付获准范围内的脱敏副本；未知字段写“未知”，不要猜测。

- 事件窗口：开始/结束时间、时区、各节点时钟同步来源与偏差。
- 环境身份：集群 UID、namespace、工作负载 kind/name/UID、Pod UID、容器名、节点名；按现场政策脱敏后保留稳定映射表。
- 版本依据：Agent commit/config hash、Kubernetes、Chart/revision、镜像 digest、引擎、通信库、驱动/固件；无法读取的项标“未知”。
- 请求条件：模型/权重 revision、输入输出长度、并发、缓存冷热、成功/失败定义与单位。
- 分段证据：提交等待、实际传输、远端完成的时间戳或明确的缺埋点说明。
- rank 信息：global/local/peer rank 与 Pod/设备映射；无法确认时标“未知”。
- 网络证据：两端同时段接口/PFC/RDMA 计数快照与区间增量、路由/链路身份；历史累计值不能直接当区间故障。
- 设备与交换机证据：采集方法、权限、端口映射和时间窗口；没有交换机遥测时不得归因交换机。
- 原始文件：文件名、字节数、SHA-256、采集命令、采集者、采集时间；不改写原始文件。
- 脱敏说明：删除/替换的 Secret、token、IP、主机名、客户数据及稳定映射规则；不得提交凭据。
- 故障注入真值：由独立评估者封存，不放入 participant bundle、Agent workspace、Skill 或提示词。
- 处置/恢复：所有写操作的批准单、唯一资源拥有者、前后快照与业务复测结果。
